# BlueGit

Descargas de **BlueGit**, el visor de repositorios Git de [Blue Blink One](https://blueblinkone.com): un grafo claro de ramas y commits, con el diff de cada cambio a un clic.

**Web:** https://bluegit.blueblinkone.com

Las versiones están en [Releases](../../releases/latest).

| Sistema | Fichero |
| --- | --- |
| macOS 14 o posterior (Apple silicon e Intel) | `BlueGit-<versión>-macos.dmg` |
| Windows 10/11 (x64) | `BlueGit-<versión>-windows-x64.zip` |
| Linux (x64) | `BlueGit-<versión>-linux-x64.tar.gz` |

BlueGit usa el `git` instalado en el sistema.

Este repositorio solo contiene las descargas; el código fuente no es público.
